# Значки лаунчера и Figma

Эти SVG являются редактируемыми исходниками проекта. В Figma импортируйте файл
как вектор и меняйте его узлы, заливку и обводку в компоненте. В WPF тот же SVG
рисует `Path`. Цвет, толщина обводки, размер и поворот задаются токенами и шаблонами
лаунчера.

| Файл | Элементы WPF |
| --- | --- |
| `trash.svg` | `DeleteBuildButton`, `DeletePersonalPackButton`, `DeleteWorldButton` |
| `chevron.svg` | `DropDownChevron`, шевроны разделов и деревьев модов |
| `back.svg` | «Назад» в подробностях сборки |
| `requirements-dot.svg` | Точка на превью сборки и в легенде |

Для обратного переноса сохраните один обычный SVG `path` с прежним `id` и
координатами `d` на месте. Сведите трансформации к координатам самого контура.
Шрифты, внешние ссылки, маски, текст и вложенные объекты этому формату не нужны.
Сборщик помещает исходные SVG в закреплённый пакет оформления вместе с офлайн
архивами карточек. Приложение открывает только файлы из проверенной таблицы пакета.
