# Что нового

## 185
- В списке передачи видны миры всех сборок. Отправить сохранение можно без переключения сборки, выбранной для игры.

## 184
- Текстуры жителей Luigi становятся выбором по умолчанию у тех, кто уже играл. THICC остаётся в списке и его можно включить вручную.

## 183
- Сборка возвращает свой порядок ресурспаков при каждом запуске. Если один из её обязательных паков выключили, он включится снова.

## 182
- В отчёт об ошибке добавлена принадлежность миров к сборкам. По списку проще определить, какие сохранения открывались с нужным набором модов.

## 181
- На тесной шкале передачи первым делом остаётся время до конца. Когда всё вместе не помещается, исчезает показ скорости.

## 180
- В отчёте об ошибке есть полный список модов и параметры запуска игры. Их больше не приходится искать и прикладывать отдельно.

## 179
- Передача мира оценивает время до получения всего сохранения. Счёт охватывает также этапы после скачивания, а не обнуляется в конце каждого шага.

## 178
- На шкале передачи мира видно, сколько ещё ждать. Оценка появляется после начала передачи данных, когда уже можно измерить скорость.

## 177
- Простой просмотр списка миров больше не меняет их привязку к сборке. Можно переключать сборки, не помечая старый мир как использованный.

## 176
- Игра снова запускается после ошибки «Could not create the Java Virtual Machine». Менять настройки Java вручную не требуется.

## 175
- На сборках с большим запасом памяти игра меньше дёргается при его заполнении. Нужная память выделяется заранее, до загрузки мира.

## 174
- Обновление сборки может заменить файл настроек, который обычно перезаписывает сама игра. Прежний пользовательский файл сохраняется для восстановления.

## 173
- Старый или скопированный мир без привязки получает её после первой игры. Лаунчер запоминает именно ту сборку, в которой его открыли.

## 172
- В отчёте появляется причина сбоя, который случился ещё до включения игрового журнала. Это помогает разобрать запуск, сорвавшийся до появления окна.

## 171
- Закрывший лаунчер друг сразу исчезает из списка получателей. Если загрузка игры сорвалась из-за мода, отправленный отчёт называет этот мод.

## 170
- У ещё не скачанной сборки рядом с именем стоит звёздочка. Её можно выбрать в списке и установить нажатием «Играть».

## 169
- В лаунчере для игры предлагаются миры выбранной сборки. Миры без указанной сборки остаются видны, чтобы их можно было открыть.

## 168
- При смене названия встроенной сборки лаунчер подхватывает миры со всеми её прежними именами. Их привязка обновляется автоматически.

## 167
- Если друг прислал мир под прежним названием его сборки, путевые точки всё равно обновляются при передаче. Переименовывать сборку обратно не нужно.

## 166
- Выбранные модели снова загружаются в Yes Steve Model. Настройки внешности, изменённые в самом моде, сохраняются после запуска через лаунчер.

## 165
- У хозяина мира больше не висит бесконечная надпись о загрузке моделей. Угол экрана остаётся свободным во время игры.

## 164
- Встроенная сборка получила имя LL8 Extended, а созданные в ней миры сохранились. Последний шаг на кнопке «Играть» теперь называется «Готовится к запуску».

## 163
- Лаунчер можно обновить, когда Steam ещё не подключён. Кнопка «Обновить» становится доступной сразу после загрузки новой версии.

## 162
- Номер выпущенной версии виден в свойствах файла LANMinecraft.exe. Его можно посмотреть даже до открытия лаунчера.

## 161
- Текущий номер лаунчера теперь виден прямо на шкале обновления. По нему можно узнать, какая версия установлена на этом ПК.

## 160
- После переноса старого мира в LL8 рядом с лаунчером остаётся отчёт. В нём видно, какие данные не перенеслись и кого это затронуло.

## 159
- Правая колонка переключается между помощником и историей обновлений. Чтобы посмотреть список версий, нажмите «Новости» в углу окна.

## 158
- Кнопка пресета больше не загорается после каждого выхода из игры. Клавиши, которых в выбранной сборке нет, не считаются неприменёнными.

## 157
- Лаунчер предлагает памяти в зависимости от тяжести сборки: лёгкой меньше, тяжёлой больше. Введённое вручную число не изменяется.

## 156
- У крупных сборок запас под служебные нужды перестал расти после достижения предела. Больше из выделенной памяти остаётся на саму игру.

## 155
- Поле памяти учитывает всю игру и сохраняет прежнюю настройку при обновлении. Если памяти не хватает, игра закрывается, прежде чем предложит открыть мир без модов.

## 154
- Подсказка у пресета называет первое назначение клавиши, которого ещё нет в игре. Описания версий в «Что нового» стали короче.

## 153
- Yes Steve Model можно отключить, чтобы снова видеть обычного персонажа. Когда мод включат обратно, он вспомнит выбранную модель.

## 152
- Поле «Сообщить о проблеме» открыто и до подключения к Steam. Если отправить отчёт пока нельзя, причина показана прямо под кнопкой.

## 151
- Свежий пресет управления виден ещё до запуска игры. Лаунчер запоминает выбор сборки, даже если выбрал её автоматически.

## 150
- Удалённые автором ресурспаки больше не остаются в списке активных. Сборка может один раз вернуть игрокам обычную модель, после чего новый выбор сохраняется.

## 149
- После обновления местности в сборке миникарта может начать отрисовку заново. Ваши путевые точки и настройки карты сохраняются.

## 148
- Передача мира автоматически подбирает скорость под соединение. Большим мирам больше не приходится ждать из-за прежнего ограничения скорости.

## 147
- В отчёте можно прочитать журналы двух предыдущих запусков игры. Из длинных журналов передаются только последние строки, чтобы не раздувать вложение.

## 146
- Подписи на кнопке «Играть» стали короткими и влезают целиком. Шкала «В ожидании мира» гаснет вместе с кнопкой «Передать», когда передавать нечего или некому.

## 145
- Автоматически включённые ресурспаки располагаются в порядке автора сборки. Текстуры из верхнего набора правильно перекрывают нижние.

## 144
- Cobblemon вернулся в сборку. Лаунчер сам скачивает Java 21, необходимую для этих модов.

## 143
- Ресурспаки, которые автор сборки пометил для включения, активируются сами. Это работает и в сборке, в которой вы уже играли.

## 142
- Лаунчер проверяет назначения клавиш перед каждым запуском игры. Повторно нажимать кнопку пресета для исправления повторов не нужно.

## 141
- Применение пресета исправляет уже задвоенные назначения клавиш. Прежняя ошибка управления больше не останавливает загрузку игры после замены раскладки.

## 140
- Если игра вылетит после появления загрузочного окна, подробности останутся в журнале лаунчера. Это помогает искать причину сбоя, который раньше не записывался.

## 139
- Лаунчер снова открывается после установки обновления. При первом появлении окна поле с ником больше не мешает запуску.

## 138
- Прокрутка ника больше не застывает при перестроении окна. Даже если поле ненадолго теряет размер, имя продолжает двигаться.

## 137
- Длинный ник движется медленнее. Теперь можно успеть прочитать даже короткий обрезанный хвост.

## 136
- Поле ника теперь замечает обрезанное имя сразу, как только окно прорисуется. Щёлкать по нему, чтобы запустить прокрутку, не нужно.

## 135
- Длинный ник автоматически прокручивается, чтобы был виден и его конец. При редактировании движение прекращается, а короткие имена остаются неподвижными.

## 134
- Значение оперативной памяти выровнено по центру поля. Число проще прочитать рядом с подписью в гигабайтах.

## 133
- Лаунчер получил тёмное оформление «Обсидиан» и шрифт Montserrat. Зелёная кнопка «Играть» теперь выделяется на общем фоне.

## 132
- Поля и кнопки одинаково подсвечиваются при наведении. Подписи разделов выровнены по одной линии, поэтому поля проще найти взглядом.

## 131
- Окно больше не срезает футер и шкалу обновления. Настройки под «Играть» разложены на две равные половины.

## 130
- Рядом с выбором сборки появилась кнопка «Пресет настроек управления»: она записывает в игру раскладку без конфликтов. Кнопка гаснет, когда пресет применён, и снова предлагает себя после изменений.

## 129
- Перед выпуском обновление проверяется на известные уязвимости в компонентах. Если проверка обнаружит уязвимость, такой файл не появится у игроков.

## 128
- Внизу окна видно, под каким аккаунтом Steam выполнен вход. Если соединения нет, там можно повторить попытку и посмотреть причину сбоя.

## 127
- Подготовка сборки показывается прямо в кнопке «Играть», у запущенной игры она так и говорит. Кнопка отчёта стала «Отправить» и встала рядом со списком.

## 126
- Справа появилась история «Что нового» с подсветкой текущего выпуска. Раздел «Сообщить о проблеме» находится рядом с передачей мира в главном окне.

## 125
- Если GitHub не завершил предыдущую публикацию, следующее обновление всё равно выходит целиком. Отсутствие промежуточного выпуска больше не мешает получить новый.

## 124
- В игре снова открывается оверлей Steam по Shift+Tab. Через него можно пригласить друга прямо из открытого мира.

## 123
- На ПК с 16 ГБ оперативной памяти лаунчер предлагает выделить Limitless 8 12 ГБ. При первоначальной настройке можно принять рекомендацию или ввести своё значение.

## 122
- Если Steam показывает друга только одному из вас, лаунчеры обмениваются сведениями напрямую. Список друзей может заполниться с обеих сторон.

## 121
- При потере пакетов лаунчер снижает темп отправки мира, а при улучшении связи снова его повышает. Передача меньше времени тратит на повторное отправление одних и тех же данных.

## 120
- Первый доступный друг автоматически подставляется в поле получателя отчёта. Если вы уже выбрали другого, подключение новых игроков этот выбор не меняет.

## 119
- Limitless 8 использует собственные настройки загрузки ресурсов. Исправлена остановка запуска после подготовки текстур, из-за которой игра могла так и не дойти до меню.

## 118
- Скин можно изменить вплоть до запуска клиента Minecraft. Отчёт об ошибке можно отправить любому другу, который сейчас в сети.

## 117
- Лаунчер повторяет запись меток карты, если файл временно удерживает другая программа. Синхронизация меток реже прерывается из-за фоновой проверки диска.

## 116
- Ник и объём памяти можно менять, пока скачиваются файлы игры. Поля блокируются только после запуска Minecraft, когда игра уже использует эти значения.

## 115
- Надпись «Версия» показывает один номер. При сравнении двух лаунчеров удобнее прочитать его целиком.

## 114
- Номер выпуска однозначно указывает, какая сборка лаунчера запущена. Если сообщить этот номер при сбое, легче найти нужное исправление.

## 113
- Лаунчер повторяет замену мода, если его временно заняла другая программа. При стойкой ошибке он объясняет, почему нельзя запустить частично обновлённую сборку.

## 112
- Встроенная сборка переходит на оригинальную TNP Limitless 8. При обновлении переносятся настройки, карты Xaero, скриншоты и резервные копии.

## 111
- Медленное получение данных в одном обмене больше не останавливает остальные. Передача мира может идти, пока другое соединение ждёт ответа.

## 110
- На быстром соединении отправка реже простаивает между блоками данных. Свободное место в очереди Steam используется быстрее.

## 109
- Список друзей лучше обновляется в больших списках Steam. После начала отправки выбранные мир и получатель закрепляются до окончания передачи.

## 108
- Друг с непрочитанными данными Steam больше не помечается как игрок со старым лаунчером. Версии сверяются при подключении, поэтому совместимая передача может начаться.

## 107
- В журнал передачи добавлены замеры реальной скорости и задержки. По отчёту можно выяснить, мешает ли передаче медленный маршрут Steam.

## 106
- Если доступна только одна сборка, её имя показывается без раскрывающегося списка. Можно сразу нажать «Играть».

## 105
- Поле выбора мира не раскрывается, если мир всего один. В поле получателя отчёта при отсутствии друзей показан статус, а единственный мир по-прежнему можно отправить.

## 104
- Друг, с которым уже установлено соединение, отображается в списке даже при скрытом статусе в Steam. Полученный от него отчёт больше не приходит от невидимого в окне игрока.

## 103
- Если список друзей пуст, в журнале появится информация о том, что ответил Steam. С этими записями проще понять, почему игроки не видят друг друга.

## 102
- При первом подключении к другу лаунчер повторяет неудачную попытку. Это помогает, когда оба только открыли лаунчер и Steam ещё готовит соединение.

## 101
- Игра подгружает модели по мере необходимости. Это снижает расход памяти при запуске тяжёлых сборок и смене ресурспаков.

## 100
- Страница проекта на GitHub теперь называется LANMinecraft, как и сама программа. Ссылки на обновления в прежних выпусках продолжают открываться.

## 99
- Получатель мира ждёт дольше, когда загрузка временно остановилась. Короткая пауза при чтении большого архива реже обрывает всю передачу.

## 98
- Большие миры быстрее передаются, когда до друга долго идут ответы сети. Лаунчер может принять больше данных подряд, поэтому отправитель реже простаивает.

## 97
- Скорость отправки мира рассчитывается по данным, которые уже дошли до друга. Полоса передачи больше не опережает сеть, пока данные стоят в очереди.

## 96
- На этапе «Копирование мира» полоса движется по мере завершения записи файлов. Она больше не доходит до края, пока последние файлы ещё копируются.

## 95
- После получения отчёта лаунчер показывает, кто его отправил и где сохранён файл. Найти полученные записи можно без поиска по всем папкам.

## 94
- Друг остаётся в списке, пока его лаунчер открыт, даже если он ничего не меняет в окне. Во время отправки отчёта видны его размер и скорость передачи.

## 93
- Друг появляется в списке, когда работает его лаунчер, даже если Steam не считает его запустившим игру. Можно выбрать его для передачи ещё до входа в Minecraft.

## 92
- Списки с сотнями меток снова синхронизируются между игроками. Большое число точек больше не вызывает скрытый отказ обмена.

## 91
- Если публикация обновления на GitHub прервётся, последняя доступная версия останется на странице релиза. Скачать рабочий лаунчер можно и во время такого сбоя.

## 90
- Если завершение передачи мира не подтверждено, его временная копия сопровождается инструкцией по восстановлению. При сбое проверки обновлений лаунчер сообщает об ошибке.

## 89
- Друг с несовместимой версией остаётся в списке. Лаунчер подсказывает, кому обновиться, прежде чем начать передачу мира.

## 88
- Отчёт об ошибке содержит до 10 МиБ свежих записей игры и лаунчера. Теперь в нём чаще видно, что вы делали перед сбоем, а не только запуск модов.

## 87
- Сетевой мир можно открыть друзьям через Steam и пригласить их из игры. Для мира, который хозяин только что открыл, больше не нужно сообщать отдельные данные сети.

## 86
- Если мир или список игроков сохранён более новой версией лаунчера, окно объясняет, что требуется обновление. Так проще понять причину отказа открыть данные.

## 85
- Список миров открывается, даже если Steam выключен или вы ещё не вошли в аккаунт. Лаунчер ждёт подключения вместо закрытия окна.

## 84
- К отчёту автоматически прикладываются версии игры и сборки, Java и список модов. Получателю больше не нужно отдельно спрашивать у вас эти сведения.

## 83
- Отчёт об ошибке можно отправить после того, как она уже произошла. В него попадают ваше описание, последние сообщения игры и свежие отчёты о вылетах.

## 82
- Старые журналы и диагностические архивы занимают меньше места. При отправке другу не нужно пересылать всю папку журналов игры.

## 81
- Отключение Steam больше не закрывает лаунчер при нажатии «Скин». Из-за потери связи не приходится снова открывать программу.

## 80
- Обновлено руководство по игре через Steam. В нём объясняется, как добавить друзей, пригласить их в мир и принять отправленное сохранение.

## 79
- При запуске лаунчер освобождает место от старых файлов VPN, голоса и среды игры. Миры, снимки экрана и личные резервные копии остаются на месте.

## 78
- Карта Xaero сохраняет доступ к меткам гостя, когда Steam выдаёт миру новый адрес. Повторный вход к тому же хозяину не создаёт пустую карту вместо знакомой.

## 77

## 76

## 75

## 74
- Прерванное обновление профилей в мире можно восстановить при следующем запуске. Лаунчер сохраняет сведения, необходимые для восстановления, даже после аварийного закрытия.

## 73
- При завершении передачи записей получатель видит и последние строки журнала. Исправлено лишнее ожидание, если соединение со Steam уже успело открыться.

## 72
- Лаунчер спрашивает согласие перед приёмом мира. В запросе видно имя отправителя, название мира и примерный размер загрузки.

## 71
- Диагностические записи теперь продолжают поступать после длинного запуска игры. Получателю виден момент сбоя, даже если игра успела записать сотни строк перед ним.

## 70

## 68

## 67
- Кнопка игры ждёт, пока лаунчер свяжет запущенный Steam с вашим профилем. Так игра не откроется под другим персонажем, у которого нет вашего прогресса.

## 66
- При подключении к Steam лаунчер может привязать ваш прежний профиль с прогрессом. Второй аккаунт на том же компьютере получает отдельного игрока.

## 65
- Входящие передачи принимаются только от друзей Steam. Незнакомый аккаунт не сможет начать обмен с вашим лаунчером.

## 64
- Из настройки сетевой игры убраны VPN и прежняя переадресация подключения. Поддерживаемый мир запускается для друзей через Steam.

## 63
- Загрузка обновления и файлов игры больше не замедляется встроенным голосовым каналом. Для разговора вместо него можно пользоваться Steam.

## 62
- Передача диагностических записей переехала из настроек голоса в главное окно. Там можно выбрать получателя и следить за состоянием отправки.

## 61
- Перед переходом на Steam лаунчер сохраняет копию прежних настроек. Она остаётся под рукой, если старую установку понадобится восстановить.

## 60
- Новый профиль Minecraft закреплён за аккаунтом Steam. Если открыть тот же мир на другом компьютере под этим аккаунтом, игра распознает того же игрока.

## 59
- Для поддерживаемых сборок NeoForge лаунчер сам подготавливает мод игры через Steam. Создавать сетевой мир и заходить к друзьям можно в нескольких сборках.

## 58
- Поддержка Steam поставляется вместе с лаунчером. Для подключения к аккаунту не нужно отдельно искать и копировать файлы Steam в его папку.

## 57
- Повреждённый мод можно восстановить загрузкой части сборки. Ради ремонта одного файла не нужно скачивать весь набор заново.

## 56
- В обновлённой сборке Infinity сохранились телепорты по меткам после перехода на новую версию NeoForge. Работают метки Xaero и FTB Chunks.

## 55
- Лаунчер повторяет сохранение настроек мира, если антивирус на мгновение занял файл. Такой короткий конфликт реже мешает запустить игру.

## 54
- Лаунчер теперь называется LANMinecraft.exe. При переходе на файл с новым именем можно оставить свои миры и настройки в прежней папке.

## 53
- Infinity доступна в списке сборок ещё до установки. Кнопка «Играть» скачивает недостающие и изменённые файлы сборки.

## 52
- В выживании без команд отключены быстрые переходы к спавну и в Незер. Модовые сборки экономнее используют выделенную память.

## 51
- Лаунчер сам ставит Java 25 для игры. Сохранённый архив позволяет восстановить повреждённую установку Java без повторной загрузки.

## 50
- Если Java завершается ещё до старта игры, лаунчер показывает причину. Можно понять, почему окно Minecraft так и не открылось.

## 49
- Поддержка игровых профилей и скинов совместима с Java 25 и продолжает работать на Java 21. При смене версии Java игра по-прежнему распознаёт вашего игрока.

## 48
- В Infinity можно телепортироваться к меткам карты FTB Chunks из выживания. Пункт доступен в меню точки, даже если команды мира отключены.

## 47

## 46

## 45
- Исправлен вылет при исследовании измерения Bumblezone. Если обновлённый мод временно не удаётся скачать, лаунчер оставляет возможность запустить игру с прежним файлом.

## 44

## 43

## 42

## 41
- Отправитель и получатель видят этапы передачи ещё до отправки архива. По полосе можно понять, когда лаунчер копирует мир, готовит данные игроков или проверяет архив.

## 40
- Большие миры передаются без прежнего ограничения на размер архива и длительность операции. Подготовка быстрее проходит по уже сжатым файлам Minecraft.

## 39
- Если основной источник мода для команд телепорта не ответил, лаунчер пробует запасной. Один недоступный адрес реже останавливает подготовку сборки.

## 38
- В поддерживаемой сборке в выживании можно просить друга о телепорте или возвращаться домой. Для этих команд не нужно выдавать себе права администратора.

## 37
- После краткого обрыва связи лаунчер пытается продолжить ту же локальную сессию. Гостю реже приходится заново заходить в открытый мир.

## 36

## 35

## 34

## 33

## 32
