# Список миров через Steam

`public_server_policy.py` — общий проверяющий инструмент поставки. Его точная
копия хранится в исходниках сборки; обязательный шаг публикации вызывается
после генерации и проверки манифеста, до загрузки любых новых assets.

```text
python tools/public_server_policy.py --pack . --manifest dist/pack-manifest.json
```

`tools/public-server-policy.json` закрепляет `schemaVersion: 1`,
`policy: "steam-only-automatic-server-list-v1"` и `reviewedInventorySha256`.
SHA охватывает полный список поставки, размеры и хеши, включая JAR,
конфиги, скрипты и ресурсы. Новый, удалённый или изменённый файл блокирует
публикацию до проверки источников автоматических серверов. Инструмент
не умеет автоматически принимать новый pin. При авторском обновлении
нужно сохранить исправления в штатном конфиге или слое сборки, проверить
новые menu/seed/native hooks и только затем явно закрепить проверенный состав.

Дополнительно отклоняются поставляемые `servers.dat`/`servers.dat_old`,
действия FancyMenu `joinserver` и включённый `AddedServerlist`. Текстовые
входы сверяются с SHA манифеста; ссылки и junction запрещены. Инструмент
только читает файлы поставки и не читает/не очищает личный список игрока.
Публичные адреса, вручную сохранённые игроком, остаются его выбором.

Pin — защита от непроверенного обновления, а не доказательство отсутствия
неизвестного поведения в любом JAR. Первичная проверка конкретного набора
и нативная приёмка принадлежат репозиторию сборки. Для Rust/меню со своими
патчами сохраняются их обязательные точные source guards и игровые проверки.

Общие тесты находятся здесь, без копирования набора в каждый репозиторий:
`python -m unittest discover -s tools/PackData/ServerPolicy -v`.
