# Контрольная точка выпуска 12 сборок

Все 12 сборок опубликованы. [Каталог на 23 записи](https://github.com/MarkZamore/LANMinecraft/blob/ec41e8fa3e8f55577d2888b2c80ab43988fedf80/catalog.json) включает прежние 11 позиций и `minecraft-12`–`minecraft-23`. В чистых публичных установках скачаны и сверены 1 700 игровых архивов (4 982 164 467 байт) и 39 305 установленных файлов. Точные версии, ревизии, результаты и ссылки ниже.

Во всех 12 проверены создание, сохранение и повторное открытие мира, заголовок окна из карточки, однократное открытие через Steam, возврат в игру, смена кнопки на «Жалобы» и запрет команд у хоста и тестового профиля гостя. В игровом чате подтверждены строка локального порта и адрес Steam с приглашением и закрытием доступа. В настоящем лобби подтверждены название мира и ник хоста. Сохранение штатного окна при неуспешном открытии, фильтрация обычных LAN-дублей и сохранность ручных серверов проверены общими стендовыми тестами адаптера. Подключение второго Steam-аккаунта везде `NOT RUN`. Computer-use не использовался.

Холодный старт публичного EXE 497 из пустой переносимой папки подтвердил 23 источника, все 12 новых карточек и обе карточки с исправленными путями. Сверены хеши кэшей запуска, манифесты, архивы карточек, состав и все 14 строк журнала. Холодный прогон занял 22 секунды. SHA256 JSON-отчёта `7bcf19ff7f8ebac0d9ec9c578ab9bdc820d5039c47b13cde2e52261547209523`. [Публичный лаунчер](https://github.com/MarkZamore/LANMinecraft/releases/tag/latest).

Исправления конкретных сборок находятся в их репозиториях. Рецепт переигрывается при новом авторском выпуске и требует пересмотра при изменении закреплённых входов. В лаунчере 497 оставлены общие механизмы Java, Forge и Steam. Для выпуска отдельных сборок новый EXE не потребовался.

После уборки в стенде осталось 13 597 884 109 байт (12,664 ГиБ). Общая проверка проекта насчитала 19,789 ГиБ при лимите 50 ГиБ. Автоматическая проверка отклонила рекурсивное удаление отдельных восстановимых папок и общего runtime с причиной `blocked by policy`. Стенд закрыт, активных игровых процессов задачи нет. Срок оставшихся данных зафиксирован в `RUN.json` на 15 ноября 2026 года, 00:08 UTC+5.

## Возобновление

1. Сверить публичный EXE 494, текущий каталог и черновики. Для всех 12 проверить [заголовок игрового окна](../../ADDING-A-LIBRARY-PACK.md#6-рано-выполнить-native-приёмку) при запуске и до/после открытия мира через Steam. Во всех состояниях требуется только название сборки из карточки. Этот сценарий добавлен к приёмке на паузе и ещё не отмечен `PASS`.
2. Первый выпуск — FTB Inferno. Его локальный манифест имеет SHA256 `88a117a8dfcb4e5b9a4cca78ecc3bf1bfffc8c2615e11a7309eb8b1463c883b3`. После обязательных проверок загрузить манифест последним, открыть выпуск, выполнить `Verify-PublicPack.ps1`, добавить карточку в свежий каталог с проверкой исходного SHA и запустить публичный EXE из чистой папки.
3. Повторно открыть сохранения All in One, Antimatter и UniversIO по SHA256 `level.dat`. Проверить Levitated и Liminal, затем оставшиеся сборки по готовности. Уже проверенные общие платформы используют прежние доказательства. Для каждой сборки проверить поведение на её авторском наборе модов.
4. UniversIO с обычным запуском в длинном пути стенда получила Windows 206. Измерено 35 012 символов аргументов. Путь `C:\LANMinecraft` даёт оценку около 25 537. Для нативной проверки сработал `Start-LocalQaJavaArgFile.ps1` с Java 17 и удалением временного файла при завершении. После паузы воспроизвести порог на обычной установке и решить вопрос общей поддержки длинной командной строки Java 9+. Файл аргументов не используется для Java 8.
5. Перед тяжёлым продолжением выполнить `python tools/workspace_storage.py --check`. Стенд `artifacts/agent-runs/atm10-style-packs-20261112` содержит точные дистрибутивы, квитанции, сохранения и журналы. Для следующего запуска брать существующий проверенный экземпляр и держать один активный игровой процесс.
