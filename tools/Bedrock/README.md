# Minecraft Bedrock Edition: подготовка поддержки

Состояние на 7 ноября 2026 года: **поддержка в лаунчере не завершена**.
Пользователю нужна полная игра без модов и бесплатный доступ для пользователей
лаунчера. Подтверждённого штатного способа выполнить это требование для игроков
без права на игру нет. Постоянный ID `minecraft-11`
зарезервирован в [общем реестре](../numbered-pack-ids.json) и не переиспользуется.
Записи в публичном `catalog.json`, игрового manifest и выпуска Bedrock нет.
Публикация одной карточки не считается рабочей поддержкой.

## Проверенные факты

- На этом Windows-ПК не найден зарегистрированный клиент, игровая запись в меню
  запуска, установка в стандартном XboxGames или запись деинсталлятора.
  Точный воспроизводимый результат регистрации и поиска миров сохраняется
  в [Verification](Verification). Отсутствие регистрации не доказывает отсутствие
  любой возможной нестандартной установки на всех дисках.
- Открыта настоящая страница Microsoft Store «Minecraft for Windows», где
  предлагается пробная версия. Установку и вход завершить не удалось; пользователь
  сообщил, что вход сейчас недоступен, затем уточнил, что нужна полная версия.
  Сбой захвата/исчезновение окна магазина не классифицирован как ошибка лицензии.
  Переустановка магазина, сброс Windows и изменение учётных записей не выполнялись.
- [Microsoft Store Catalog API](https://displaycatalog.mp.microsoft.com/v7.0/products/9NBLGGH2JHXJ?market=US&languages=en-US)
  для продукта `9NBLGGH2JHXJ` подтверждает семейство
  `Microsoft.MinecraftUWP_8wekyb3d8bbwe`, имя `MICROSOFT.MINECRAFTUWP`, сертификат
  Microsoft Corporation и `IsDemo=false`. Это сведения о продукте, не о покупке
  текущего пользователя. Наличие установленного пакета и успешная активация тоже
  не подтверждают право запуска полной версии.
- [Официальная страница полной игры](https://www.xbox.com/en-US/games/store/minecraft-for-windows/9NBLGGH2JHXJ)
  ведёт в штатный канал Store/Xbox. Steam не предоставляет лицензию Bedrock.
  [Инструкция пробной версии](https://www.minecraft.net/en-us/free-trial)
  включает вход Microsoft; пробная версия не заменяет требуемую полную игру.

## Граница бесплатного доступа

Сама интеграция может быть бесплатной. Однако она не предоставляет пользователю
лицензию полной Bedrock. [EULA Minecraft](https://www.minecraft.net/en-us/eula)
связывает право загрузки/установки/игры с покупкой и отдельно ограничивает раздачу
игрового программного обеспечения без разрешения Mojang/Microsoft. Публикация EXE
Bedrock как обычного payload сборки не является подтверждённым способом поставки.

Для части пользователей дополнительная покупка не требуется:
[Mojang объединил Java и Bedrock для ПК](https://www.minecraft.net/en-us/article/java---bedrock-edition-pc-out-june-7)
и предоставил вторую редакцию владельцам первой. Это доступ по уже имеющемуся
праву на игру, с соответствующей учётной записью; бесплатным доступом для всех
пользователей LANMinecraft он не является. Индивидуальные права здесь не проверены.
Бесплатный dedicated server также не заменяет полный игровой клиент.

Таким образом, при текущем требовании бесплатной полной игры без покупки для
всех пользователей публикация рабочей карточки не подготовлена. Недоступный вход
на этом ПК отдельно препятствует native-испытаниям; это другая граница,
не доказательство невозможности Steam-транспорта.

## Воспроизводимая проверка Windows

Требуется PowerShell 7.2+ на Windows. По умолчанию инструмент только читает
регистрацию текущего пользователя и форму каталогов миров. Он не читает базу
мира, не копирует её, не переписывает профили и настройки, не меняет связи папок.
Личные пути, имена миров и ID игровых профилей в обычный JSON не входят.

```powershell
.\tools\Bedrock\Probe-WindowsClient.ps1
.\tools\Bedrock\Test-WindowsClientProbe.ps1
```

После штатной установки полной версии пользователь может запустить отдельную
проверку активации:

```powershell
.\tools\Bedrock\Probe-WindowsClient.ps1 -Launch
```

Она принимает только зарегистрированное production-семейство Microsoft со
Store-подписью и нормальным статусом. AUMID читается из его manifest, активация
выполняется штатным Windows API без произвольного EXE или shell-команды из данных.
Успешный ответ API означает запрос активации, а не доказанный вход в игру.
Отсутствующий, поддельный, неоднозначный или неисправный пакет не запускается.
`-OpenStore` отдельно открывает фиксированную официальную страницу;
он не покупает и не устанавливает игру. `-IncludePersonalPaths` разрешает личные
пути только для локальной диагностики; такой вывод не публиковать.

Код завершения: `0` для завершённого чтения, в том числе `not-installed`;
`2` при ошибке обнаружения; `3` при отказе/ошибке запрошенной активации;
`4` при ошибке запроса магазина. Проверять также поля JSON: наличие файлов
миров не означает исправную базу или закрытую игровую сессию.

## Миры и сохранение личных данных

[Microsoft документирует переход UWP на GDK](https://learn.microsoft.com/en-us/minecraft/creator/documents/gdkpcprojectfolder)
и новые данные под `%APPDATA%\Minecraft Bedrock`. Проба проверяет пользовательские
профили GDK и прежний UWP-каталог; Preview и общие ресурсы `shared` не считает
мирами обычных игроков. Reparse-пути пропускаются. Найденная структура
`level.dat` + `db` обозначается только как кандидат мира.

Нынешний обработчик миров LANMinecraft использует Java NBT, `session.lock`
и Java/Steam-профили. Он не подходит Bedrock; см. [аудит кода](ARCHITECTURE.md).
Для Bedrock нужны отдельные чтение/блокировка базы, сохранение игровых
идентификаторов и проверенный экспорт/импорт. Перенос в `Minecraft/Worlds`,
перенаправление штатного хранилища и переписывание UUID не реализованы.
Настройки и миры существующих сборок не менялись.

## Игра через Steam остаётся непроверенной

[Документация BDS](https://learn.microsoft.com/en-us/minecraft/creator/documents/bedrockserver/server-properties?view=minecraft-bedrock-stable)
описывает LAN-исключение для `online-mode` и требует Xbox для удалённых клиентов.
Это не испытание обычного Windows-клиента и его встроенного хоста. Возможность
LAN через локальную точку Steam нельзя считать ни доказанной, ни принципиально
невозможной по одному этому правилу.

[Mojang объявил смену транспорта с 29 октября 2026 года](https://help.minecraft.net/hc/en-us/articles/49914677714957):
актуальному BDS нужны NetherNet, TCP-сигнализация и UDP. Старого предположения
«прокинуть UDP 19132» недостаточно.
[Протокол NetherNet](https://mojang.github.io/bedrock-protocol-docs/guides/nether-net-onboarding-guide/)
описывает HTTP/WebRTC, ICE и игровые identity assertions. Его политики сервера
не доказывают поведение штатного клиентского LAN-хоста.

[SteamNetworkingMessages](https://partner.steamgames.com/doc/api/ISteamNetworkingMessages)
может переносить сообщения, но не выдаёт игровую сессию Microsoft/Xbox и не
предоставляет право на игру. Нынешние Java-адаптеры не являются поддержкой Bedrock.
Новый транспорт должен проверяться отдельно на полном клиенте и двух настоящих
участниках. Пока не реализованы игровой мост, Steam discovery миров Bedrock
и подстановка никнейма/скина Steam.

## Подготовленный текст будущей карточки

Имя: **Minecraft Bedrock Edition**. Содержательных модов: **0**.
Это черновик для будущего `library/content.json` исходного репозитория сборки;
он ещё не является опубликованными метаданными и не подключён к лаунчеру.

Исследуй бескрайний мир, где за лесами и горами скрываются пещеры и древние руины. Добывай материалы, создавай инструменты и строй дом, который станет началом большого поселения. Выращивай урожай, приручай животных и готовься к опасностям ночи. Отправляйся в необычные измерения, находи сокровища и побеждай сильных противников. Выбирай между спокойным творчеством и выживанием, превращая каждый новый мир в собственное приключение.

## Приёмка перед публикацией

1. Получить доступный полный Windows-клиент штатным способом; покупку и вход
   выполняет пользователь. Подтвердить фактическую версию, регистрацию и API запуска.
2. Проверить запуск, новый технический мир, сохранение, повторный вход и личные
   настройки. Получить фактические пути/формат хранения без изменения старых сборок.
3. Отдельно испытать локальное подключение с текущей авторизацией клиента,
   транспорт встроенного хоста, затем соединение через Steam. Не смешивать лицензию,
   игровую личность и аутентификацию с передачей байтов.
4. Реализовать отдельный внешний runtime/capability и необходимую поддержку миров
   по [аудиту](ARCHITECTURE.md), пройти адресные проверки и обязательный Release.
   Сохранить свежий manifest перед «Играть», очередь подготовки и интерфейс.
5. Сначала выпустить проверенный лаунчер, затем исходный репозиторий сборки,
   проверенные данные и только после этого запись GitHub-каталога с `minecraft-11`.

Изменений реализации лаунчера сейчас нет. Общий Release и завершённый QA-аудит
не повторяются; выполняются только проверки новых инструментов и реестра.
Контентные исправления в лаунчере отсутствуют; переносить их в сборку не требовалось.
