# Пресеты управления сборок

Пресет принадлежит GitHub-репозиторию сборки, а не версии лаунчера. Файл `launcher/controls-preset.txt` входит в обычный `pack-latest` и проверяется SHA-256 манифеста. Репозитории выбираются из каталога GitHub или пользовательского `portable-pack-source.json`; отдельного списка сборок с пресетами в программе нет.

## Изменение и публикация

1. В репозитории сборки измените таблицу раскладки или входные данные её `tools/keybinds/build_preset.py`, как описано в `tools/keybinds/design.md` этой сборки.
2. Пересоберите `launcher/controls-preset.txt`, затем запустите `python tools/keybinds/check_preset.py`. Проверяйте реальные зарегистрированные назначения, сохранность базового управления и конфликтные контексты установленной версии Minecraft/Forge/NeoForge.
3. Добавление файла включает предложение пресета, изменение заменяет предлагаемую раскладку, удаление файла отключает предложение. При намеренном удалении обновите генератор и CI-проверку сборки, чтобы следующий запуск генератора не восстановил файл.
4. Отправьте изменения в `main` сборки и дождитесь успешного `publish.yml`. Достаточно обновить сборку на GitHub, выпускать лаунчер заново не требуется.

## Когда игрок видит изменения

При запуске лаунчер получает проверенный снимок каталога и манифестов сборок с GitHub. После этого при открытии окна и выборе установленной сборки отдельно загружаются её небольшие файлы `launcher/`; моды, миры и полный клиент ради пресета не скачиваются. Если пресет исчез из проверенного манифеста, удаляется только его локальная копия; личные назначения игрока остаются.

Снимок остаётся неизменным до закрытия лаунчера, как и версии самих сборок. Чтобы увидеть публикацию, сделанную после открытия окна, перезапустите лаунчер. Это не обновление программы. При недоступности GitHub используется последний проверенный снимок; неудавшаяся загрузка не удаляет предыдущий пресет.

Кнопка предлагает применить раскладку только при отличии от личного `options.txt`. Скачивание пресета не меняет управление само: игрок нажимает кнопку и подтверждает замену. Удаление предложения также не откатывает уже выбранные игроком клавиши.

## Проверки лаунчера

`ControlsPresetRemoteSyncTests` выполняют цикл добавления, изменения, удаления и восстановления через загрузчик GitHub-манифеста и ZIP. Проверяются сохранность личных настроек, отсутствие загрузки модов и поведение при ошибках. `ControlsPresetWatchTests` проверяют вызовы при запуске и выборе сборки.
