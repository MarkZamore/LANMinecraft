# Проверка действующего сервера обновлений

После сборки кандидата:

```powershell
dotnet run --project tools/UpdateCheckProbe -p:BuildProjectReferences=false -- . artifacts/agent-runs/<task-id> <installed-commit-sha>
```

Сначала создайте `RUN.json` в каталоге задачи. Консоль вызывает настоящий
`UpdateService.CheckAsync` один раз, без запуска интерфейса, установки или
скачивания EXE. Она записывает `live-check.json` с исходами HTTP-маршрутов
и подтверждённым результатом проверки. Не передавайте секреты в аргументах.
Результаты остаются внутри папки проекта. Недоступный ответ завершает
проверку с кодом 1, без утверждения об актуальности установленной версии.

Резервный путь соответствует официальному [GitHub Release Assets API](https://docs.github.com/en/rest/releases/assets#get-a-release-asset).
Для манифеста проверяются размер и SHA256 актуального asset, а для EXE и
дельт также сохраняются проверки по проверенному манифесту лаунчера.
API JSON вместо бинарного ответа не считается успешной загрузкой манифеста.
