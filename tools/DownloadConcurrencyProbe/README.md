# Сравнение параллельных загрузок

Инструмент вызывает настоящий `PortableGameInstaller.Install`, включая запись файлов, SHA-1 и повторы запросов. Он использует официальный адрес ресурсов Mojang и HTTP-настройки лаунчера. Существующий игровой кеш служит только источником индекса, каждый прогон заново получает выбранные файлы по сети.

Перед запуском проверить бюджет через `python tools/workspace_storage.py --check`. Создать отдельный каталог `artifacts/agent-runs/<task-id>` и записать владельца, назначение, срок удаления, ожидаемый размер и нужные результаты в `RUN.json`. Папка `downloads` должна отсутствовать или быть пустой. Установленные сборки и пользовательские миры для замера не требуются.

```powershell
$env:JAVA_HOME = 'C:\Tools\jdk-25.0.2'
dotnet run --project tools/DownloadConcurrencyProbe -- `
  Minecraft/Launcher/Shared/assets/indexes/34.json `
  artifacts/agent-runs/download-concurrency-20261117 `
  768 4,8,16,32,64,128 2
```

Путь JDK и индекс выбираются для текущего компьютера. Пять аргументов задают индекс, каталог результатов, число файлов, уровни параллельности и число повторов. Выборка равномерно берётся по отсортированным уникальным хешам и сохраняется в отчёте. На чётных повторах порядок уровней разворачивается. Каждый уровень использует новый HTTP-клиент с одинаковыми настройками.

`results.json` содержит SHA-256 индекса, точный состав выборки, время с записью и проверкой файлов, число HTTP-запросов и ошибок, успешность и среднее время по каждому уровню. Сравнивать успешные повторы одного состава. Показания зависят от сети и сервера во время замера. Скачанные файлы удаляются в `finally` после каждого уровня. После аварийного завершения проверить свою папку перед повтором и убрать собственные промежуточные файлы.

## Замер 17 ноября 2026 года

Windows build 26300, .NET SDK 10.0.404, Minecraft 26.3, индекс `34.json` с SHA-256 `fbaf1d88b1f14358682a986a8a1a21d26e3e0cefec12881768d6395001ee6508`. Равномерная выборка содержала 768 файлов общим размером 64,09 МиБ из 5 149 уникальных ресурсов. Каждый прогон загружал весь одинаковый набор заново. Порядок уровней чередовался.

Все 21 прогона завершились успешно. В каждом выполнено ровно 768 запросов, без HTTP-ошибок и повторов, размер и SHA-1 проверены производственным установщиком. Для лаунчера выбрано 64 одновременные загрузки. Увеличение до 128 и 256 в дополнительном сравнении дало средние времена 16,96 и 19,37 секунды. Разница между сериями показывает влияние текущей сети, поэтому время конкретной будущей установки может отличаться.

Заключительный прогон с 64 загрузками получил весь индекс из 5 149 файлов размером 464,78 МиБ за 82,49 секунды. Все размеры и SHA-1 совпали, выполнено ровно 5 149 запросов, HTTP-ошибок и повторов не было. Полный индекс проверялся одним прогоном, сравнение параллельности выполнено на одинаковой выборке из 768 файлов.
